#Using library is much better that writing all calculations from scratch.
# DistanceProgram
```python
from math import sqrt, pow
#Gather data
"X1=float(input(""enter the first value of the first point""))"
"X2=float(input(""enter the first value of the second point""))"
"Y1=float(input(""enter the second value of the first point""))"
"Y2=float(input(""enter the second value of the second point""))"
#Calculations
"D = sqrt(pow(X2-X1, 2) + pow(Y2-Y1, 2))"
#Display output
print (D)
```
# With the help of libraries, codes are not only more simpler and shorter now, but it also saves time, and improve efficiency.
# without the use of the functions sqrt() and pow(), the code would have been longer because it will calculate manually, like pow(y2-y1, 2) will be" the answer to y2-y1 times answer to y2-y1"
